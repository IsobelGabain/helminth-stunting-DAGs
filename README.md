# helminth-stunting-DAGs
R code to construct directed acyclic graphs (DAGs) visualising the  potential causal effect of helminth infection on childhood stunting,  using the ESC-DAGs method. Three DAGs: children >6 months, children  &lt;6 months, and maternal. Gabain et al. (2025) Phil Trans R Soc B.  https://doi.org/10.1098/rstb.2025.0040
